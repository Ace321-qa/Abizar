# Abizar El-Andrawi Platform

Node.js + Express + EJS + JSON file storage (MVP).

## Stage 1 — Scaffold

Current state: base app skeleton, folder structure, and layout/theme are in place.
Public/admin routes, data layer, and CRUD land in later stages per `architecture.md`.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

Visit http://localhost:3000
